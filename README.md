# NarrFlow 下载

本仓库用于发布 NarrFlow Windows 安装包和已签名的客户端更新信息。项目源码在独立的私有仓库维护。

**[下载最新版本](https://github.com/wktdh/NarrFlow-Releases/releases/latest)**

## 安装与升级

支持 Windows 10/11 x64。打开最新版本页面，下载 `NarrFlow-Setup-<版本>.exe`，运行后按安装向导选择安装位置、桌面快捷方式以及安装完成后是否启动。

升级时直接运行新安装包覆盖安装，无需先卸载。升级前请保存编辑内容，重要业务数据建议备份。0.1.2 及更早版本需要手动覆盖安装一次 0.1.3，后续版本可从客户端提示更新。

安装包采用本机自签名证书，尚未获得 Windows 公共信任，Windows 或 SmartScreen 仍可能显示发布者提示。签名与文件校验用于验证更新来源和完整性。

## 客户端更新

客户端启动后后台检查新版本，也可在「设置 → 执行环境 → 检查更新」中手动检查。仅在用户点击下载后才获取安装包，校验通过后由用户选择「退出并安装」。更新不会自动执行业务流程。

下载与检查更新无需登录 GitHub。首次使用网页自动化时，可能需要在设置中另行安装浏览器执行环境。

每个版本提供安装包、更新 JSON、更新签名、校验和及构建器元数据。更新 JSON 和签名是客户端使用的配套文件，普通用户只需下载 EXE 安装包。
